# STATECRAFT: PRESIDENT — сборки для Android

Мобильная стратегия: вы — президент реальной страны. Здесь публикуются только готовые APK; исходный код закрыт.

## Как установить
1. Откройте раздел **[Releases](../../releases/latest)** и скачайте файл `Statecraft-<версия>.apk`.
2. Откройте файл на телефоне. Если Android спросит — разрешите установку из этого источника.
3. Требования: Android 7.0+ (64-битный процессор ARM64).

## Обновления
- Игра при запуске сама проверяет, есть ли новая версия, и показывает кнопку «Доступна новая версия — скачать».
- Новая версия ставится поверх старой — сохранения остаются (все сборки подписаны одним ключом).

## Статус
Ранний прототип: экономика, правительство, визы, строительство и 3D-мир (глобус → страна → город).
Интерфейс отладочный, события и выборы ещё в разработке.
